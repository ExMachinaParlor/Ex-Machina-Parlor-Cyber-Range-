Need another way in?

If you do not have your own device or need help getting access, ask an EMP Range Crew member. EMP has a self-hosted KasmVDI server; the crew can arrange access and help you get started.

Before your session

  1. Confirm this range is running and choose an exercise with the EMP Range Crew.
  2. Get your assigned account and target scope from the crew.
  3. Review the event rules, available time, and how to request help or a reset.
  4. Record what you tried, what changed, and the evidence you observed.

Use only the systems and activities assigned for your session; coordinate changes and resets with the crew.

Your session

Explore domain services, departmental file shares, and Windows access controls. Ask the crew which tasks are available for the conference.

Suggested starting exercise

Compare access to an assigned departmental share with access to a restricted share using the account provided by the crew. Record the expected and observed results.

What to take away

Understand domain membership, group-based permissions, and how to validate a segmented enterprise lab.

Inside the range

Explore the emprange.net domain across server, workstation, and DMZ networks. The repository includes a Ludus configuration, custom Ansible roles, a network diagram, deployment instructions, and validation checks.

What to explore

Review domain services and replication, departmental SMB shares and access controls, Windows domain membership, and connectivity to the Apache intranet server.

Get started

Use the repository README to prepare the required Ludus templates, install the roles, load range-config.yml, and deploy. Follow its validation checklist before starting an exercise. The documented VM allocations total 36 GiB RAM, excluding host overhead.
