Need another way in?

If you do not have your own device or need help getting access, ask an EMP Range Crew member. EMP has a self-hosted KasmVDI server; the crew can arrange access and help you get started.

Before your session

  1. Confirm this range is running and choose an exercise with the EMP Range Crew.
  2. Get your assigned account and target scope from the crew.
  3. Review the event rules, available time, and how to request help or a reset.
  4. Record what you tried, what changed, and the evidence you observed.

Use only the systems and activities assigned for your session; coordinate changes and resets with the crew.

Your session

Ask the crew which range-day configuration is running. The public archive describes EMP-FAK4, but does not establish the current conference setup.

Suggested starting exercise

Review the event topology with the crew, identify your assigned systems, and follow the exercise selected for this session.

What to take away

Document your route through the exercise, the evidence you collected, and any questions for the walkthrough.

The range-day archive

The repository is described as a record of EMP range events and walkthroughs. Its current README introduces the EMP-FAK4 configuration and links to a range-day network diagram.

Explore the configuration

Start with the published diagram to understand the documented environment, then browse the repository for configuration files and any available event materials.
